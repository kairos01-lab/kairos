# Código de Conduta

## Nosso compromisso

Este é um espaço para pesquisa, aprendizado e colaboração. Esperamos respeito
entre todas as pessoas, independentemente de experiência, origem, identidade ou
opinião técnica.

## Comportamentos esperados

- Critique ideias, não pessoas.
- Explique o contexto e o que você tentou.
- Presuma boa-fé.
- Não publique credenciais, dados pessoais ou conteúdo sensível.
- Não faça assédio, discriminação, ameaça ou ataques pessoais.

## Comportamentos inaceitáveis

- Assédio, intimidação, linguagem ofensiva ou discriminatória.
- Publicar dados privados de terceiros.
- Spam, ataques coordenados ou interrupção deliberada de discussões.
- Usar o projeto para controlar sistemas reais sem autorização.

## Aplicação

O mantenedor pode remover comentários, fechar issues ou bloquear participantes
que violem estas regras. Para relatar um problema, abra uma issue privada ou
entre em contato com o mantenedor sem publicar dados sensíveis.
